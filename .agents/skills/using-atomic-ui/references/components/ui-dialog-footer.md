# ui-dialog-footer

Dialog Footer — Feedback & Overlay, Stable.

Dialog footer

Shadow DOM: yes (style via CSS variables / ::part)

## Props

| Attribute / prop | Type | Default | Description |
|---|---|---|---|
| `align` | `"center" \| "end" \| "space-between" \| "start"` | `'end'` | Horizontal alignment of footer content |
| `divider` | `boolean` | `true` | Show/hide the top divider border |
| `sticky` | `boolean` | `false` | Pin the footer to the bottom of the dialog when content scrolls |
