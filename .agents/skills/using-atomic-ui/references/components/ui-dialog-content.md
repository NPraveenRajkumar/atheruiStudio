# ui-dialog-content

Dialog Content — Feedback & Overlay, Stable.

Dialog content

Shadow DOM: yes (style via CSS variables / ::part)

## Props

| Attribute / prop | Type | Default | Description |
|---|---|---|---|
| `loading` | `boolean` | `false` | Show loading/skeleton state |
| no-padding (`noPadding`) | `boolean` | `false` | Remove default padding |
| `scrollable` | `boolean` | `false` | Allow content area to scroll vertically |
