# category-section

## Props

| Attribute / prop | Type | Default | Description |
|---|---|---|---|
| category-icon (`categoryIcon`) | `string` | `'📦'` | Category icon |
| category-name (`categoryName`) | `string` | — | Category name |
| `components` | `ComponentData[]` | `[]` | Components in this category |
| `expanded` | `boolean` | `true` | Whether the section is expanded |
| `mode` | `"demo" \| "doc"` | `'demo'` | Mode: 'demo' or 'doc' |
